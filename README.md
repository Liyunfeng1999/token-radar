Token Radar ranks the 198 pre-token protocols in DefiLlama's sealed snapshot by the implied value of a future token launch — the whole 40-protocol watchlist plus every rankable protocol below the floor — and serves a static dashboard with the board, a detail view and farm plan for each protocol, and the live-token protocols set aside.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
